# SEO Tema Kurulum Rehberi

## Tema nasıl kurulur
1. Repository içeriğini ZIP olarak paketleyin (tema kökünde `style.css` görünecek şekilde).
2. WordPress panelinde **Görünüm > Temalar > Yeni Ekle > Tema Yükle** adımlarını izleyin.
3. ZIP dosyasını yükleyip temayı etkinleştirin.

## Menü nasıl atanır
1. **Görünüm > Menüler** bölümüne gidin.
2. Yeni menü oluşturun veya mevcut menüyü seçin.
3. Menü konumlarından:
   - **Primary Menu** (üst menü)
   - **Footer Menu** (alt menü)
   alanlarına atama yapın.

## Logo nasıl değiştirilir
1. **Görünüm > Özelleştir > Site Kimliği** bölümüne gidin.
2. **Site Logosu** alanından yeni logoyu yükleyin.
3. İsterseniz **Görünüm > Tema Ayarları** içindeki `Logo URL` alanını da kullanabilirsiniz.

## Tema Ayarları nerede
- WordPress panelinde **Görünüm > Tema Ayarları** bölümündedir.
- Buradan header CTA, hero, paket, iletişim, sosyal medya ve footer alanları yönetilir.

## Ana sayfa nasıl ayarlanır
1. **Ayarlar > Okuma** bölümüne gidin.
2. "Ana sayfanız görüntülensin" seçeneğini **Sabit bir sayfa** yapın.
3. Ana sayfa olarak oluşturduğunuz sayfayı seçin.
4. `front-page.php` otomatik olarak landing page tasarımını kullanır.

## Paket bilgileri nasıl değiştirilir
1. **Görünüm > Tema Ayarları** bölümüne gidin.
2. **Paketler** alanında Bronze, Gümüş, Altın kartlarını ayrı ayrı düzenleyin:
   - paket adı
   - fiyat ve periyot
   - özellik listesi (satır satır)
   - buton metni ve URL
   - öne çıkan paket seçeneği
